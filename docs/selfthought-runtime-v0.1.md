# SELFTHOUGHT Runtime v0.1

REALITY_ID != INSTANCE_ID != SESSION_ID != ACTIMANIRUN_ID != THOUGHT_ID != BIRTH_ID.

A SELFTHOUGHT is an immutable UTF-8 byte artifact plus explicit identity, origin, matter/reality manifests, receiver manifest, gate, status, and lineage.

Lifecycle:
BIRTH -> CAPTURE -> HASH -> ADDRESS -> CONTEXTUALIZE -> RESOLVE -> EMIT -> RECEIVE -> READ -> UNDERSTAND -> GATE -> SELFSHIFT -> RECEIPT -> LINEAGE

A thought is not authority. A receipt is not effect. Observation is not authority. Missing authority is never inferred.

ADDRESSELF treats filesystem paths as locations, not identities. Identity is carried by instance_id, birth_id, content_hash, reality_id, and parent_id.

Gate progression is explicit: RECEIVED -> UNDERSTOOD -> GATE_BLOCKED, or RECEIVED -> UNDERSTOOD -> GATE_PASSED -> SELFSHIFTED.

This v0.1 core is substrate-neutral and does not require Ollama, Hermes, Hugging Face, or any particular model provider.
