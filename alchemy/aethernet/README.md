# ALCHEMYSELFTELLIGENCE / Aethernet Transition Contract v0.1

This artifact establishes the contract before a runtime harness is permitted to implement it.

## Topology

FOREIGN / OPEN TOPOLOGY
→ NETWORK INGRESS
→ UNKNOWN PREIMAGE
→ IDENTIFICATION
→ PREIMAGE PARSER
→ AETHER_IN
→ MEMBRANE / POLICY ENGINE
→ ADMITTED AETHER_OUT
→ ACTUATOR ENGINE
→ REALISELF

Network sockets remain the transport boundary. Aether descriptors are internal membrane primitives.

## Descriptor rule

AETHER_IN is the classification-domain ingress for untrusted matter.

AETHER_OUT is an admitted-matter channel. Foreign input has no write authority to AETHER_OUT. The resident Aethernet daemon is the only writer.

## Resident execution rule

Foreign input does not become permission to spawn an arbitrary execution identity. The resident Aethernet daemon owns ingress, classification, membrane, actuation, and receipt formation.

## Witness rule

stdout and stderr are independent evidence streams. Neither stream alone establishes success or failure.

## Contract boundary

This contract does not execute anything and does not grant authority. It defines what the harness may distinguish, preserve, and subsequently prove.

## First proof

The first Aethernet node proof is an observable path:

foreign ingress → AETHER_IN → membrane → admitted actuator → receipt

with no foreign surface acquiring direct execution authority.
